📥 安装

方式一：下载 zip（推荐）

  1. 下载 pubcode-v1.1.0-win64.zip
  2. 解压到任意目录
  3. 在该目录打开 CMD / PowerShell 即可使用
D:\tools\pubcode\
├── pubcode.exe            主程序
├── ffmpeg\
│   ├── ffmpeg.exe         ffmpeg 主程序（勿删）
│   ├── ffprobe.exe        ffprobe（勿删）
│   └── ffplay.exe         可选，pubcode 不使用
├── README.md              本文件
└── LICENSE-ffmpeg.txt     ffmpeg 许可说明

方式二：源码运行

git clone https://github.com/yourname/pubcode.git
cd pubcode
python pubcode.py --version

方式三：加入 PATH（可选）

把 D:\tools\pubcode\ 加入系统 PATH 后，可在任意目录直接运行 pubcode。

系统要求： Windows 7 x64 及以上（推荐 Win10/11），无需安装 Python（zip 版），磁盘约 200MB（含 ffmpeg）。

🎬 动作详解

vc:v1 — 视频转码 · 默认行为（不写任何选项）

项目默认值
视频编码H.265 (libx265) + hvc1 tag
码率控制CRF（H.265=28，H.264=23）
编码预设slow
像素格式智能（8bit→420p，10bit→420p10le，4:2:2/4:4:4 保留）
HDR智能（源 HDR → 目标 SDR 自动 tonemap）
帧率保留源；VFR 源用 passthrough
音频编码HE-AACv2 48k（缺失 libfdk_aac 时降级 AAC 128k）
多声道6ch 以上自动降混 2ch
容器MP4 + +faststart
元数据encoder=pubcode v1、comment=pubcode v1

示例

pubcode.exe vc:v1 in.mkv out.mp4          :: 全自动
pubcode.exe vc:v1 in.mkv                  :: 只给输入，自动生成 in.pubcode.mp4
pubcode.exe vc:v1 in.mp4 out.mp4 --codec h264
pubcode.exe vc:v1 in.mp4 out.mp4 --crf 20
pubcode.exe vc:v1 4k.mp4 out1080p.mp4 --resolution 1920:1080
pubcode.exe vc:v1 hdr.mp4 hdr_out.mp4 --hdr hdr10
pubcode.exe vc:v1 hdr.mp4 sdr.mp4 --tonemap on
pubcode.exe vc:v1 in.mp4 out.mp4 --mode 2pass --video-br 4M
pubcode.exe vc:v1 in10bit.mp4 out8bit.mp4 --tenbit 0
pubcode.exe vc:v1 in.mp4 out.mkv          :: 输出 MKV

av:co — 音视频封装

流复制（-c copy），不重编码。写入 encoder=pubcode v1、comment=pubcode v1，输出 MP4 加 +faststart。

pubcode.exe av:co in.mp4 out.mp4
pubcode.exe av:co in.mp4        :: 生成 in.pubcode.mp4
pubcode.exe av:co in.mp4 out.mkv

验证打标 ffprobe ... | findstr /i "encoder comment"

HDR 参数

参数取值默认

音频参数

参数取值默认
--audio-codecaac / fdk_he_v2fdk_he_v2
--audio-br48k / 64k / 128kHE=48k, AAC=128k

HE-AACv2 强制立体声，6ch 以上自动降混。缺失 libfdk_aac 降级 AAC 128k。

--hdr 行为

值行为
auto源 HDR → 保留 HDR；源 SDR → 输出 SDR
sdr强制 SDR 输出（源 HDR 时自动 tonemap）
hdr10强制 HDR10 输出（写入 master-display + max-cll 元数据）
hlg强制 HLG 输出

CRF 参考值

CRFH.264H.265
18视觉无损视觉无损
20极高质量极高质量
23均衡（推荐）—
26—高质量
28—均衡（默认）
30+—小体积

H.265 CRF 28 画质大致相当于 H.264 CRF 23。

🧠 智能决策机制

位深决策

源位深--tenbit输出
8bit未指定8bit
8bit110bit
10bit未指定10bit
10bit08bit（error_diffusion 抖动）

HDR 决策

源 HDR--hdr输出
SDRautoSDR
HDR10autoHDR10（保留元数据）
HLGautoHLG
HDRsdrSDR（自动 tonemap，按源曲线分流）
SDRhdr10HDR10 标记（内容仍是 SDR，不推荐）

色度决策

源像素格式输出
yuv420p*yuv420p / yuv420p10le
yuv422p*yuv422p / yuv422p10le（x265 main422-10）
yuv444p*yuv444p / yuv444p10le（x265 main444-10）

帧率决策

源帧率类型--fps输出
CFRsource保留源帧率 + -fps_mode cfr
VFRsource保留 VFR + -fps_mode passthrough（不补帧）
任意数字强制该帧率 + -fps_mode cfr

容器 & 音频决策

.mp4/.m4v/.mov-movflags +faststart
.mkv无（matroska）
.ts-mpegts_flags +resend_headers
无扩展名自动补 .mp4
无音频-an
1ch/2chHE-AACv2 48k
6ch/8chHE-AACv2 48k + -ac 2 降混

🔄 典型场景

压缩手机视频（节省 50-70% 体积）

pubcode.exe vc:v1 phone.mp4 out.mp4 --crf 30 --preset medium

4K 电影转 1080p

pubcode.exe vc:v1 movie_4k.mkv movie_1080p.mp4 --resolution 1920:1080 --crf 24

转 H.264 兼容老电视

pubcode.exe vc:v1 in.mp4 out_compat.mp4 --codec h264 --audio-codec aac --preset slow

网络分享（限制码率）

pubcode.exe vc:v1 in.mkv share.mp4 --mode 2pass --video-br 3M --resolution 1280:720

HDR 电影保持 HDR

pubcode.exe vc:v1 hdr_movie.mkv hdr_movie_out.mp4 --hdr hdr10 --crf 22

HDR 电影转 SDR（老播放器）

pubcode.exe vc:v1 hdr_movie.mkv sdr_movie.mp4 --hdr sdr --tonemap on

下载的视频重新封装

pubcode.exe av:co downloaded.mp4 out.mp4

批量处理（批处理脚本）

for %%f in (*.mkv) do pubcode.exe vc:v1 "%%f" "%%~nf.mp4"

❓ 常见问题

Q1: 提示"找不到 ffmpeg.exe" → 确认同级 ffmpeg\ 子目录含 ffmpeg / ffprobe。

Q2: 音频输出是 AAC 不是 HE-AACv2 → --version 看 libfdk_aac 是否为 yes，否需 nonfree 构建。

Q3: HDR 转 SDR 画面发灰 → 检查 zscale / tonemap 是否 yes，缺失时降级。

Q4: 转码卡住 CPU 不动 → v1.0.2 起已修复管道死锁，可临时 show_stderr=True 排查。

Q5: 杀毒软件报警 → PyInstaller 打包误报，加入白名单。

Q6: 输出文件 0 字节 → 检查磁盘空间 / 路径权限，加 show_stderr=True 排查。

Q7: VFR 视频转码后卡顿 → v1.1.0 已自动 passthrough，可尝试 --fps 30。

Q8: HDR10 元数据丢失 → v1.1.0 已自动读写，源无元数据时用行业默认值并警告。

Q9: 2-Pass 第一遍看起来没有缩放 → 正常行为，第一遍只做码率统计，已剔除缩放。

Q10: 进度条 ETA 不准 → 前 10% 因编码器初始化偏大，之后趋于稳定。

📋 ffmpeg 能力自检

项目说明
ffmpeg 路径必须指向解压目录内的 ffmpeg\，不能是 system32
libfdk_aacyes → HE-AACv2 可用；no → 降级 AAC
zscaleyes → HDR tonemap 高质量
tonemapyes → 支持色调映射
-fps_modeyes → 用新版参数
-vsyncyes → 用老版参数（一般新版这里是 no）
如果 libfdk_aac / zscale / tonemap 有 no，建议换 BtbN/FFmpeg-Builds 的 nonfree 完整构建。
